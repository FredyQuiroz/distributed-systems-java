# Sistemas distribuidos en Java / Distributed systems in Java

[Español](#español) · [English](#english)

## Español

Ejercicios para entender cómo se comunican dos programas. Cada ejemplo divide el trabajo entre un programa que pide algo y otro que responde.

### Esta revisión

**2011-05-01 · Enseñar TCP, UDP y llamadas RMI.** Incluye clientes y servidores para intercambiar mensajes mediante TCP y UDP, y una consulta remota de figuras mediante RMI. Los ejemplos permiten comparar el intercambio directo de mensajes con una llamada a otro programa.

### Cómo explorar el código

Instala un JDK y empieza en la clase principal de la edición que quieras explorar.

- [Linux/1/UDPCliente.java](Linux/1/UDPCliente.java)
- [Linux/1/UDPServidor.java](Linux/1/UDPServidor.java)
- [Linux/2/TCPCliente.java](Linux/2/TCPCliente.java)
- [Linux/2/TCPServidor.java](Linux/2/TCPServidor.java)

## English

Exercises for learning how two programs communicate. Each example divides the work between a requesting program and a responding program.

### This revision

**2011-05-01 · Demonstrate TCP, UDP, and RMI.** Include clients and servers that exchange messages over TCP and UDP, and a remote shape lookup over RMI. The examples let readers compare direct message exchange with a call into another program.
